## 🙋‍♀️ Sobre Mim

Analista de Dados focada em transformar volumes de dados em *insights* claros e acionáveis. Apaixonada por criar relatórios interativos, automatizar processos analíticos e aplicar inteligência de dados para solucionar problemas reais.

- 📍 **Localização:** São Paulo, Brasil
- 🚀 **Foco Atual:** SQL, Python, Power BI, DAX e Modelagem de Dados
- 💡 **Diferencial:** Combinar design intuitivo (UI/UX) na construção de dashboards para contar histórias claras através dos dados.
